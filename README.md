# Iroto Web — photo-library picker restored / no fullscreen 8

版本：`2.14.1-beat-haptic-stronger-logo-v3-browser-nofs8`

直接基于 nofs7 修改：撤回 iPhone/iPad 的“仅从文件选择”方案，保留 nofs7 的录制计时文字对齐修正。

## 这次的改动

- 恢复原来的 `accept="image/*"` 图片选择入口，不再为 iOS 设置 `application/octet-stream`。
- 首页、演奏页替换照片继续使用同一个图片选择控件，无新增中间弹窗。
- 三语按钮统一恢复「写真を選択 / 选择照片 / Choose Photo」，不再显示“选择图片文件”。
- 取消 nofs7 为通用文件入口增加的专用类型检查，回到原图片解码流程。取消、空选择或解码失败仍保留当前照片；再次选择同一照片仍可触发导入。

## iPhone 使用

点击选择照片后，在系统来源菜单里选择「照片图库」，导入已经保存在“照片”中的图片。程序不再要求先转存到“文件”。

这是恢复图库可用的原有入口，不是只保留图库的特殊接口。系统仍可能显示「拍照」或「选取文件」；本版没有声称能删除原生菜单的拍照项。网页自身不提供拍照按钮、不设置 capture，也没有新增摄像头访问或自动保存照片功能。需要新照片时，请先用系统相机拍好，再从图库导入。

## 保持不变

CSS 与 nofs7 逐字节相同，包括计时数字的 text-box-trim 对齐修正、毛玻璃背景、居中计时框和控制栏显隐时的位置变化。录制时仍显示红白白白节拍点，每拍亮起 280 ms，间隙消失；不录制时不显示视觉节拍。

不自动全屏、横竖屏方向同步、传感器处理、准星平滑、声音、强弱拍振动、录制计时、视频画幅及保存逻辑均未改。SVG、PNG、manifest 与 sw.js 也保持原样；加速度依旧不参与准星控制。

## 更新

解压后，将文件夹内的内容覆盖到现有网站发布目录，保持 index.html 位于原位置，无需新建仓库或改变网址。兼容性窗口和 HTML 资源查询参数的版本后缀为 `nofs8`。

nofs7 原包未覆盖。此次只发布可下载的项目文件，未直接更改已部署的网站。

## 检查与限制

详见 CHECKS.md。完成本地 Chromium 的按钮文案、图片选择配置、实际图片解码、取消与失败处理、演奏中换图、计时框和实际录制下载检查。

没有实体 iPhone/iPad Safari 测试。模拟用户代理不能复现系统照片来源菜单，不能代替原生图库、HEIC 解码、照片权限或旧 Safari 版本的实机验证。
