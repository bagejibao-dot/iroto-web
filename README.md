# Iroto Web — recording timer with beat dot / nofs5

版本：`2.14.1-beat-haptic-stronger-logo-v3-browser-nofs5`

直接基于 nofs4 修改，没有回退到早期全屏或加速度试验分支。

## 本次改动

取消非录制时的常驻视觉节拍器。录制时只显示一个“小圆点＋时间”的毛玻璃胶囊；圆点在时间左侧，原来的 REC 文字移除，也没有单独的右侧节拍圆点。

圆点继续跟随既有音频的四分音符位置：第 1 拍红色、第 2／3／4 拍白色，每拍亮起后回落到低亮度。八分音符细分不额外闪烁。视觉反馈只在录制中运行，音频及原有强弱拍振动没有改变。

## 位置与显示

- 竖屏、两种横屏均为顶部居中，与顶部栏的实际可见区域中心对齐；安全区使用原顶部栏几何位置，不重复扣除边距。
- 保留顶部栏避让：顶部栏显示时计时框位于其下，隐藏时计时框上移到顶部区域。原来的 180 ms 动画、点击穿透和减少动态效果处理保留。
- 计时框保留半透明深色底及 10 px 毛玻璃模糊。圆点缩为 10 px 并置于框内，不画外环。
- 低高度横屏时，仅缩小计时框高度／栏下间距，避免贴住中央停止键；原有控制按钮不移动。
- 未录制演奏、录制待机、停止、保存弹窗及首页都不显示此提示。重新录制时计时从 00:00 开始。
- 横竖屏切换和操作栏显隐不会重新开始计时或改变小节位置。

## 保持不变

不自动全屏、演奏中横竖屏轴向同步、传感器／准星手感、音频、强弱拍振动、照片比例、视频编码与时长修正、保存流程均保持 nofs4。提示仍是独立 DOM，不进入导出视频。图标、manifest 和 Service Worker 文件逐字节未改。

## 更新网页

将本文件夹内全部文件覆盖到原发布目录，保持 index.html 位于原位置。资源查询参数已更新；在兼容性检查中确认版本后缀为 nofs5。无需新建仓库。本包没有覆盖之前的 nofs4 存档。

见 CHECKS.md。本次做了本地 Chromium 离线页面、移动尺寸及实际录制／下载检查，没有在实体 Android 或 iPhone Safari 上验证，不承诺覆盖所有浏览器和既有问题。
