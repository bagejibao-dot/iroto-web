# Iroto Web — visual metronome / no fullscreen 3

版本：`2.14.1-beat-haptic-stronger-logo-v3-browser-nofs3`

基于当前非全屏、横竖屏轴向同步版本（nofs2）修改；不是此前的加速度或全屏试验分支。

## 显示方式

- 演奏中始终显示右侧单点视觉节拍器，无论是否录制。第 1 拍亮红色，第 2、3、4 拍分别亮白色，每拍后回落至低亮度。八分音符细分不额外闪烁。
- 录制时左侧显示 `REC 00:12`。删除原计时文字前的圆点，避免出现两个节拍提示。不录制时计时胶囊隐藏。
- 待机、停止以及返回首页时，整个演奏状态层隐藏。

## 对齐与位置

按本次最终要求：**左侧是录制计时，右侧是节拍圆点**。

录制胶囊直接读取现有语言选择框的实际左边线、宽高和圆角。节拍器的圆心使用问号按钮的横坐标，与现有底部录制按钮共轴。左右边距不另行硬编码成另一套横竖屏数值；已有安全区布局也沿用。

顶部栏显示时，两侧提示位于栏底下方 12 CSS px。顶部栏隐藏时，两侧同步上移到原控制栏所在的顶部区域。竖屏、两种横屏都采用左计时、右节拍的布局。单纯切换控制栏时使用 180 ms 平移，不弹跳、不缩放；屏幕尺寸变化时重新计算锚点。系统设置为减少动态效果时关闭平移动画。

提示层不拦截触摸或点击，点击其所在照片区域仍切换控制栏显隐。提示在控制栏下层移动，避免在滑动过程中覆盖按钮。

## 节奏与录制

视觉节拍直接读取原有 `triggerTick()` 的四分音符位置及音频时间，不创建第二套节拍计时器。第一拍视觉脉冲 140 ms，其余三拍 90 ms；160 BPM 一拍为 375 ms，均短于一拍。每拍只做一次视觉脉冲，第一拍仍保留原来的双脉冲震动，其他三拍保留原来的短震动。

录制时间仍使用既有的开始时间和更新间隔。长时长采用紧凑数字样式，在同宽胶囊内显示小时。显隐控制栏和屏幕旋转不重新开始计时、不重置拍数。

这些是独立 DOM 提示，不绘入录制画布。导出视频继续只包含原来的照片、准星/轨迹及声音。

## 保留原有功能

- 不自动申请全屏，没有恢复全屏重试。
- nofs2 的屏幕方向同步及切换后重新校准保留。
- 传感器、灵敏度、准星平滑、取色及音频逻辑保留。
- 加速度仍不参与准星控制。
- 强弱拍震动、视频编码、时长元数据处理及保存流程保留。
- 原 logo、桌面图标、manifest 和 Service Worker 文件逐字节不变；manifest 仍为 browser 模式。

## 更新

解压 ZIP，把文件夹内的内容覆盖至原 GitHub Pages 发布目录，保持原来的 `index.html` 位置。无需新建仓库或修改网址。兼容性检查中的版本标识以 `nofs3` 结尾；HTML 资源查询参数同步更新。

## 验证范围

见 `CHECKS.md`。已完成本地 Chromium 中的布局、交互、模拟旋转与实际 MediaRecorder 下载检查。模拟移动尺寸、缺失振动 API 的环境不等于实体 iPhone Safari 测试；实体手机传感器、系统键盘、振动硬件和浏览器动画仍需实机核对。
