# Iroto Web — dark help & filename viewport / nofs11

版本：`2.14.1-beat-haptic-stronger-logo-v3-browser-nofs11`

直接基于 nofs10 修改。新增 `ui.css`，用独立的 `.ui-dialog` / `.ui-sheet` 样式替换旧的白色保存、兼容性窗口；演奏画布和原控制栏仍沿用原 `styles.css`。

## 文件名与 iPhone 键盘

原文件名 contenteditable 继承标签的 13px 字号。改为独立的 16px 字号、24px 行高、普通文本块排版；不再继承小字标签样式或使用缩放。保留默认名称全选、退格删除、中间编辑和纯文本粘贴。IME 转换中的 Enter 不结束编辑，正常 Enter 收起输入焦点。

保存、帮助及删除确认弹窗按 VisualViewport 的实际宽高和偏移布局。键盘弹出只调整弹窗，不改舞台大小、照片比例或 viewport 的缩放上限。特别窄高的可见区采用紧凑布局；键盘收起后做有限次数重测。只在缩放比例不变时恢复本次编辑前的文档滚动位置，不强制重置用户手动缩放。

这些是针对性修正，尚未实体 iPhone Safari 测试。模拟视觉视口不代表真正执行了 Safari 的输入框自动放大算法。

## 校准图标

回正按钮内部的字体字符改为中心对称的 24×24 SVG 图标。按钮外圈、位置、点击事件和校准算法不变；使用白色，与其他控制图标统一。

## 软件帮助

原问号入口改为帮助，不再显示兼容性检测列表。没有移动现有问号或语言按钮的位置。

帮助采用“实际按键符号 + 对应文字”的逐项说明，而不是在小截图上叠加容易重合的指示线。内容含照片导入、播放/停止、校准、BPM 长按、录制待机/保存、显隐控制栏、录制计时/节拍点、语言切换，以及颜色与声音的对应规则。中文、日语、英语均提供完整内容。

左上角 X 关闭；标题和版本页脚不随正文滚动。完整版本号位于底部，可自动换行。帮助打开时不会停止原有演奏/录制；录制期间会明确提示仍在录制。

## 颜色说明基于当前源码

- 代表色相对应 C、D、E、F、G、A、B：红、橙、黄、绿、青、蓝、紫。
- 明暗影响八度/音域，鲜艳程度影响声音强弱；浅淡颜色有原有补正。
- 黑、白、灰及浅淡颜色符合实际阈值时为 Rest，伴奏节拍继续。
- 不声称不同颜色切换不同乐器音色。当前合成与取样规则未修改。

## 统一深色 UI

首页照片选择为深色白边按钮。保存、删除二次确认和帮助均使用深色背景、浅色文字、白灰边线；删除操作保留红色提示。文件名有可见光标与选区。不会因为点击弹窗外部而删除录制。

原生照片来源菜单、权限窗口、系统键盘与浏览器下载 UI 不属于网页，仍由手机系统控制。

## 保持原样

- 不自动全屏；nofs2 起的屏幕旋转轴同步、校准与准星平滑保留。
- 加速度不参与控制；强弱拍振动、280ms 红白白白录制节拍点不变。
- iPhone playback 音频会话、音频合成、节拍调度与取色逻辑不变。
- nofs10 码率策略、录制画布、视频编码/音轨、时长元数据处理不变。
- SVG logo、PNG 图标、manifest 与 Service Worker 文件不变。
- 演奏状态计时框的毛玻璃、字形对齐、定位与上下移动不变。
- 新帮助/保存窗口不绘入视频。

## 更新网站

解压，将项目文件夹内全部内容覆盖到原 GitHub Pages 发布目录，保持 index.html 的位置。**必须一并上传新增的 ui.css**，只替换 app.js 会缺少新弹窗样式。

资源查询参数和帮助窗口底部版本号以 `nofs11` 结尾。原 nofs10 压缩包没有修改。本次没有直接部署到用户网站。
