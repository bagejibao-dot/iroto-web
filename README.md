# Iroto Web — visual metronome / nofs4

版本：`2.14.1-beat-haptic-stronger-logo-v3-browser-nofs4`

基于当前 `nofs3` 视觉节拍器版。本次只修改状态层的外观，并更新版本及资源查询参数。

## 节拍器

右侧节拍器改为直径 16 CSS px 的单个实心圆。去掉外层圆框和底色；原 26 px 对齐容器仍在，但完全透明且没有边框。圆点有轻微柔和阴影，方便在浅色照片上辨认，不再呈现「外环＋内圆」的按钮外观。

第 1 拍红色，第 2、3、4 拍白色，每拍后回落到灰色。颜色时序、脉冲时长、音频时间基准和原有强弱拍振动均未改。

## 录制计时框

`REC＋时间` 使用与现有顶部／底部控制栏相同的半透明深色背景及 10 px 背景模糊，同时保留 `-webkit-backdrop-filter` 声明。仅模糊背后的图像，文字本身不模糊。

继续按语言选择框的实际位置测量左边线、宽度、高度和圆角。右侧节拍圆心仍与问号按钮、底部录制按钮共轴。顶部栏显隐时的上下移动、点击穿透及隐藏条件不变。

## 保留

- 不自动全屏；演奏中的横竖屏轴向同步保留。
- 不加入加速度控制，不调整准星灵敏度、平滑或姿势校准。
- 视频录制、计时、保存和时长元数据处理不变。
- 状态层仍不进入导出视频。
- 原有 SVG、PNG 图标、manifest、Service Worker 逐字节保留。

## 更新

解压后，将文件夹内的文件覆盖到原网页发布目录，保持 `index.html` 的位置不变。兼容性检查中的版本应以 `nofs4` 结尾。旧的 `nofs3` 包未覆盖。

## 检查范围

见 `CHECKS.md`。已做本地 Chromium 离线布局、背景模糊像素对比及实际录制下载检查；没有在实体 Android 或 iPhone Safari 上验证。
