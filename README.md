# Iroto Web — recording timer with beat dot / nofs6

版本：`2.14.1-beat-haptic-stronger-logo-v3-browser-nofs6`

直接基于 nofs5 修改。本次只调整录制计时框内节拍圆点的亮灭方式和时长。

## 节拍圆点

第一拍红色，第二、三、四拍白色。每拍保持亮起 280 毫秒，之后完全隐藏，直到下一拍；不再保留灰色底点或暗色阴影，也不渐暗成灰色。

当前 BPM 范围为 60–160。最高 160 BPM 时一拍为 375 毫秒，因此 280 毫秒亮起后仍有 95 毫秒的完全隐藏间隙。代码另以当前一拍的 75% 为上限，若将来提高 BPM，也会为间隙保留时间。这里描述的是音频时钟驱动的目标时长，实际呈现仍受到浏览器刷新和设备性能影响。

圆点只改变透明度，不移除布局占位，所以时间文字的位置不随闪烁变化。仍然只在录制时显示，不恢复常驻视觉节拍器。

## 保持不变

- 顶部居中的计时框位置、横竖屏对齐、控制栏显隐时的上下移动。
- 半透明深色底和 10 px 毛玻璃效果；仅圆点本身的灰色底与阴影被去掉。
- 第一拍双脉冲、其他三拍短震的触觉节拍；音频节拍与音符规则。
- 非全屏模式、横竖屏控制轴同步、姿势校准、传感器和准星手感。
- 录制计时、照片比例、视频画布、编码、下载与删除流程；计时提示不绘入视频。
- Logo、桌面图标、manifest 和 Service Worker 文件。
