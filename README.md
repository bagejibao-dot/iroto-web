# Iroto Web — no fullscreen 2 / screen rotation mapping

版本：`2.14.1-beat-haptic-stronger-logo-v3-browser-nofs2`

基于当前 `Iroto_Web_logo_v3_browser_no_fullscreen.zip`（nofs1）修改。不是此前的加速度试验分支。

## 本次修正

上一版的画面允许随系统旋转，但演奏坐标仍使用开始时保存的方向。本版在演奏中检测到屏幕实际旋转后，更新横竖屏映射及左右横屏方向。

屏幕方向以 `screen.orientation` 为主；缺少该接口时兼容 `window.orientation`。都不可用时才按可视区域宽高判断横竖屏，此时无法可靠区分两种横屏方向。不会用姿态传感器的 alpha/beta/gamma 来决定切换屏幕方向。

实际方向改变后，等待约 180 ms 合并旋转过程的重复通知，重新采集当前握持姿势作为基准。准星沿用原来的平滑参数回到中央，不会直接瞬移；清除旧的拖尾，避免连接跨方向的轨迹。接下来可直接继续倾斜演奏，无需停止再播放或手动点击回正。

旋转期间不停止演奏或录制，不重置 BPM、节拍计数、录制计时，不改变独立视频画布的尺寸。停止、换图或返回时会取消尚未完成的方向切换处理。

## 保持原样

- 不主动进入全屏，也没有全屏重试机制。
- 系统方向锁定尝试仍保留上一版行为；系统实际允许页面旋转时，本版跟随新的方向映射。
- 加速度依旧不参与准星控制。
- 灵敏度、矩阵计算、准星平滑、手动回正、拍节强弱震动及音频/视频处理未改。
- `styles.css`、manifest、SVG logo、三种 PNG 图标、`sw.js` 与 nofs1 逐字节一致。

## 更新网页

解压后，将本文件夹内的文件覆盖到原网站发布目录，保持 `index.html` 的位置不变。无需更改网址。

兼容性窗口的版本标识以 `nofs2` 结尾；HTML 内资源查询版本同步更新。此包与上一版分开保留。

## 检查范围

具体检查见 `CHECKS.md`。已做本地 Chromium 的模拟屏幕旋转、模拟姿态输入和实际浏览器录制/下载测试。没有实体 Android 或 iPhone Safari 的传感器、系统动画、硬件触觉测试，不能据此保证所有手机表现完全相同。
