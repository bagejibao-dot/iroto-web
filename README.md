# Iroto Web — nofs14

版本：`2.14.1-beat-haptic-stronger-logo-v3-browser-nofs14`

直接基于本对话的 nofs13，只调整使用帮助窗口的关闭按钮。

## 改动

- 关闭 X 从标题左侧移到右侧。标题两侧仍保留相同的 44px 栏位，标题保持居中。
- 保留按钮原有 1px 细圆边框；去掉自动获得焦点时额外出现的 2px 白色外轮廓。
- 点击区域仍为 44×44px，X 的 SVG、尺寸、居中和关闭事件不变。键盘聚焦时只提亮现有的细边框，不另加外圈。
- 保留帮助正文、播放／停止间的斜杠、底部版本号和独立滚动。

除版本常量外，app.js 与 nofs13 逐字节一致；不修改传感器、声音、录制、输入框、页面缩放或其他功能。styles.css、logo、桌面图标、manifest 和 sw.js 均未更改。

## 更新

解压后把项目文件夹内的内容覆盖至原网站目录。至少要同步更新 index.html、ui.css 和 app.js；新资源版本后缀为 nofs14。没有直接更改已部署的网站，原 nofs13 包保留。

## 验证范围

见 CHECKS.md。本地 Chromium 中核对三语、横竖屏和关闭操作；没有实体 iPhone Safari 或 Android 测试。本版只处理帮助关闭按钮，不宣称消除了其他既有问题。
